
## 結構

- 單一 html 檔 (`index.html`), 分成兩區, 用註解標出邊界
    - 資料區: 兩段 `<script type="application/json">`, 純 JSON, 沒有函式. 換主題只改這一區
        - `#history-data`: 所有主題內容
        - `#land-topo`: 海岸線 (TopoJSON), 上方註解註明來源與產生方式
    - 結構區: 結構 + 主題 (`<style>`)、引擎 (`<script>`), 不含任何主題內容. 引擎用 `JSON.parse` 讀資料區
- 引擎分 8 段, 依序是: 錯誤顯示、外部相依檢查、資料載入與檢查、名稱排版 (純計算)、地圖圖層、狀態與動作、模組、啟動
- 模組: 頁面文字、地圖、時間軸、政權狀態、事件卡、名稱開關
    - 每個模組是 `{ name, el, update }`, `update` 只讀 `state`
    - 改變狀態一律呼叫 `actions` (`select` / `setYear` / `setView` / `toggleKind` / `toggleLayer`), 再由 `render()` 通知所有模組
    - 模組之間不直接互相呼叫

## 錯誤與外部相依

- 外部相依寫在 `<script data-global="...">` 一處, 引擎啟動時檢查; 缺了就在頁面最上方列出缺哪個檔案和網址, 不會只剩空白頁
    - d3 7.9.0、topojson 3.0.2 (cdnjs): 需要網路
    - Google Fonts: 載不到時改用系統字型, 不影響功能
- 資料區 `#history-data` 找不到或不是合法 JSON: 頁面最上方顯示錯誤 (寫出 id 與原因), 頁面無法運作
- 資料區 `#land-topo` 是可選的: 找不到或壞了, 地圖只少海岸線 (地圖上顯示一行提示, 原因寫在 console), 其他照常
- `#history-data` 載入時逐項檢查 (日期格式、地點與政權代號、時間軸範圍、色塊圓心半徑); 有錯的項目略過, 並在頁面最上方逐條列出
- 每個模組的繪圖都包在 `guard()` 裡: 某個模組出錯, 只有那一塊顯示錯誤, 其他模組照常; 地圖的每個圖層也各自有保護

## 地圖圖層 (決定地圖上 "畫什麼")

- 不同主題要不同的呈現方式, 所以呈現方式拆成圖層, 由資料區 `#history-data` 的 `layers` 決定開哪些, 預設開或關 (`on`); 開著的圖層在地圖左上第二排各有一個開關
- 目前有兩個圖層 (引擎的 `LAYERS`)
    - `focus` 事件焦點: 只畫目前事件相關的政權 (事件的 `p` 加上 `involves`). 適合講事件故事
    - `territory` 統治範圍: 畫當年所有政權. 適合講勢力消長
    - 兩個都開時, 同一個政權只畫一次
- 新增呈現方式 (例如行進路線): 在 `LAYERS` 加一個 `{ draw(ctx) }`, 再到資料區的 `layers` 開啟它, 不用改其他模組
    - `ctx` 提供: 該圖層專用的 `<g>`、`path`、`proj`、`year`、目前的 `event`、`labels` (要參加名稱排版就 push 進去)

## 換資料 (資料區 `#history-data`)

- 純 JSON: key 與字串都用雙引號, 不能寫註解 (欄位說明在資料區上方的 html 註解); 字串裡不能出現 `</script` 與 `<!--`
- 日期一律寫字串 `"YYYY"` / `"YYYY-MM"` / `"YYYY-MM-DD"` (西元), 引擎換算成時間軸位置. 不支援西元前
- 同一個日期只寫一次
    - 政權的 `start` / `end` 決定: 時間軸底色的分段、色塊的預設起訖、長條在 `end` 時歸零
    - 事件與政權交接寫同一個日期 (例: 澎湖海戰 `1683-07-16` = 清朝 `start`), 不用另外對齊
- `kinds`: 地圖名稱的類別與開關按鈕. `rank` 越小越先放; `polity` 是政權名稱 (必要); `centered: true` 的類別名稱寫在點的正中央, 不畫點
- `polities`
    - `color`: `[淺色, 深色]`, 引擎產生 CSS 變數 `--p-<id>`
    - `share`: `[日期, 比例]`, 右欄長條 (示意)
    - `areas`: 統治範圍色塊, 每塊一個圓 (`c` 圓心 `[經度, 緯度]`, `r` 半徑 km, `from` / `to` 不寫就跟政權起訖相同); 同一政權的圓合成一塊
    - `labelAt`: 政權名稱的位置 (不寫就用最大那塊的圓心)
- `events`: `p` 是事件發生時的政權; `involves` 是其他相關的政權, 事件焦點圖層會一起畫 (只畫事件當下還在統治的)
- `eras`: 時期 (時間軸底色 + 頁面下方簡介). 起點 = 該政權 `start`, 第一個從時間軸起點開始
- `map.views`: 地圖範圍按鈕, 第一個是預設; 事件地點不在目前範圍時, 自動換成第一個放得下的範圍
- 換地區要一起換資料區 `#land-topo`: 用 mapshaper 從 Natural Earth `ne_10m_land` 裁出範圍轉 TopoJSON, 整段貼進去 (物件名稱要是 `land`, 引擎讀 `objects.land`)

## 注意事項

- 名稱排版 (`placeLabels`, 純計算): 依 `rank` 一個一個放 (事件地點最先), 每個名稱依序試候選位置, 都會擋到就不顯示
    - 事件地點與政權名稱一定顯示 (只換位置)
    - 同樣的畫面每次結果都一樣, 拖時間軸時字不會跳
    - 字框用瀏覽器實際量; 網頁字型載入完成後會清掉重量
- 被藏起來的名稱: 滑鼠移到點上 (12px 內最近的點) 會顯示
- 縮放只拉開距離, 字和點維持原大小; 可拖曳範圍比畫面多半個寬高
- 鍵盤是整頁通用的一個 `keydown`: ← → 上一則 / 下一則, Home 第一則, End 最後一則, 數字跳到第幾則, 單獨按 0 第一則
    - 數字先跳再修正: 按 1 馬上到第 1 則, `TYPE_WAIT` (0.4 秒) 內再按 2 改到第 12 則; 輸入滿位數, 或後面不可能再接數字時, 不再等下一位
    - 任何換事件的操作 (點事件、拖紅線、上一則 / 下一則) 會清掉輸入到一半的數字
- 事件卡高度固定為最長那則 (所有事件疊在同一格); 加長事件內容會讓右欄變高, 1366x768 螢幕上右欄已接近底部
