
## 結構

- `index.html` 分三個區塊: 結構 + 主題 (`<style>`)、資料 (`<script>` 開頭的 `PLACES` / `EVENTS` / `POLITIES`)、引擎 (同一個 `<script>` 的其餘部分)
- `land-10m-tw.js`: 海岸線資料, 第一行註明來源與產生方式
- 外部相依: d3 7.9.0 與 topojson 3.0.2 (cdnjs)、Google Fonts. 需要網路, 斷線時地圖與時間軸畫不出來

## 換資料

- `PLACES`: 地點. `k` 是名稱開關的類別 (`site` 史蹟 / `city` 城市 / `region` 地區)
- `EVENTS`: 事件. `y` 是西元年, 用小數表示月份 (例: 1683.54 約 7 月中), 決定時間軸位置與先後; `p` 是事件發生時的政權
- `POLITIES`: 政權
    - `k`: `[年, 比例]`, 右欄長條的長度 (示意)
    - `areas`: 統治範圍色塊, 每塊是一個圓 (`c` 圓心經緯度, `r` 半徑 km, `from` / `to` 起訖年); 同一政權的多個圓會合成一塊
    - `labelAt`: 名稱固定寫在哪個經緯度 (不填就寫在最大的那塊圓心)
- `ERAS`: 時間軸底色的時期分段
- `VIEWS`: 兩個地圖範圍按鈕各自的經緯度框
- 換地區要一起換海岸線: 用 mapshaper 從 Natural Earth `ne_10m_land` 裁出範圍, 再包成 `window.LAND_TOPO = ...;`

## 注意事項

- 名稱排版: 依優先順序放字 (事件地點 > 政權 > 城市 > 史蹟 > 地區), 每個名稱依序試 右上 / 右下 / 左上 / 左下, 都會擋到別人就先不顯示; 事件地點一定顯示. 滑鼠移到點上 (12px 內最近的點) 可看被藏起來的名稱
- 縮放只拉開距離, 字和點維持原大小, 所以放大後被藏的名稱會出現
- 鍵盤是整頁通用的一個 `keydown`: ← → 上一則 / 下一則, 1-9 跳到該則, 0 最後一則
- 事件卡高度固定為最長那則 (所有事件疊在同一格), 加長事件內容會讓右欄變高; 1366x768 螢幕上右欄已接近底部
- `y` 相同或很接近的事件, 時間軸會自動排到下一列
