# 多視角流程圖 (Code Flow)

- 一個複雜的流程 (程式的 / 商業的), 用 "同一張圖 + 多個視角" 解釋給不同的人聽
- 節點位置不動, 切視角只換卡片內容與顏色, 讀者不用重新認地圖
- hover 卡片看 "為什麼有這一步"、查證過的事實與來源; 點流程卡片, 圖上只留那條路
- 範例資料: 結帳付款流程 (使用者 / Dev / 風險 三個視角)
