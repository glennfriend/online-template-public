# 放假日曆 (Holiday Calendar)

- 一年的放假日整理成三種可複製的格式: TSV (貼 Google Sheets 自動分欄)、純文字 calendar、Markdown table
- 日期排序可切換 小到大 / 大到小, 三種格式一起變
- 範例資料: 2027 台灣假日、美國 federal holidays、美國夏令/標準時間切換日
