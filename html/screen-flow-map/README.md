# 畫面流程地圖 (Screen Flow Map)

- 把一個網站的使用流程, 畫成一個個 "故事": 顧客從哪裡進站, 依序看到哪些畫面, 按了什麼, 最後停在哪
- 每個畫面是一個小視窗框, 寫出 `看得到` 與 `可以做`, 顧客實際按下的那一項用 ▶ 標出來
    - 外部網站虛線框, 我們的網站實線框, 彈出視窗雙線框; 例外情況 ("如果 ..., 會被帶去哪") 寫在框的下方
- 畫面之間用箭頭連起來: 箭頭上寫顧客做了什麼, 箭頭下寫系統在背後做了什麼
- 同一步有好幾種結果時畫成分岔; 有問題的那一條標成紅色
- 每個故事下方固定 4 欄: 出現條件 / 完成 / 接著 / 補充
- 流程索引: 依入口 (搜尋引擎, 社群, 廣告, Email, 合作網站) 與依功能, 點一下跳到故事
- 網址索引: 每個網址一列, 有說明, 參數, admin 標記, 以及用到這個網址的故事
    - 滑過畫面的網址列看完整網址; 點一下跳到網址索引那一列並閃一下, 右上角出現 `回到故事` 按鈕
- 參考資料 (可收合): 問題清單 (已確認 / 沒確認), 比較卡片, 差異表 (欄位與列數自訂)
- 單一 html 檔, 直接雙擊打開就能用; 淺色 / 深色跟著系統設定
- 範例資料: 虛構的居家選物網站 "Cozy Mart", 16 個故事分 5 組 (購買, 帳號, 訂單, 付費會員, 廣告與其他入口), 35 個網址分 8 組
